## Project Summary :
  **MiniSpamFilter using Naive Bayes (Problem Statement 9)**
  We implemented a Mini spam filter in C++ using Naive Bayes logic . We implemented Tokenisation,Naive_bayes                    logic, data shuffling , 80-20 data split , text file parsing , stringstream method and some necessary file-i/o with some concepts of OOPS (classes , inheritance , destructors ).
  We have attached a uml diagram(`uml.pdf`) and a report file(`cpp_project_report_version2.pdf`) explaining the                      above in detail in the root directory itself.

## Instructions to run the project : 
  1. Ensure you have a C++ compiler installed .
  2. Open your terminal in the repository's root directory and run the following command to compile all the source files together : ```g++ main.cpp naive_bayes.cpp tokeniser.cpp -o spam_filter```
  3. Alternatively , open the project file in any code editor (like VScode) , ensure all files are in the same folder , then run the same command mentioned in step 2.
  4. After compiling , type "```./spam_filter```" in terminal.
